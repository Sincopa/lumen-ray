Lumen Portable, Windows 10/11 x64

Распакуйте ВЕСЬ архив в отдельную папку. Не запускайте EXE прямо из ZIP.
Lumen.exe и папка runtime должны оставаться рядом.

Запустите Lumen.exe. Интерфейс и диагностика запуска встроены в приложение.
При ошибке WebView2, повреждении runtime или сбое инициализации появится
системное окно с причиной и путём к журналу. Отдельный скрипт запуска не нужен.

Если WebView2 Runtime отсутствует, окно ошибки предложит открыть официальный сайт:
https://developer.microsoft.com/microsoft-edge/webview2/
Выберите Evergreen Runtime. Установка требует подключения к интернету.

Журналы (их можно отправить разработчику):
%LOCALAPPDATA%\app.lumen.desktop\logs\startup.log
Если папка недоступна, журнал записывается в TEMP:
%TEMP%\lumen-startup.log.
Журналы запуска не содержат ссылок подписок, паролей или ключей подключения.

Если Windows или антивирус блокирует программу до запуска, внутри EXE невозможно
показать сообщение. В этом случае проверьте историю защиты Windows.
